> 分析时间：2026-05-06

## 一、项目定位

**WeKnora** 是腾讯开源的、面向企业级的 **LLM 驱动知识框架**，核心目标是让分散的文档转化为可查询、可推理、持续演化的知识资产。

三大核心能力：

- **RAG 快速问答** — 基于知识库的精准检索问答
- **ReAct Agent 智能推理** — 自主编排检索、MCP 工具、网络搜索处理复杂多步任务
- **Wiki Mode 自动知识库** — Agent 将原始文档自动蒸馏为相互链接的 Markdown Wiki 页面 + 可视化知识图谱

## 二、技术栈分析

### 2.1 后端（Go 1.24）

| 层次 | 技术选型 |
|------|---------|
| Web 框架 | Gin + CORS 中间件 |
| ORM | GORM（支持 PostgreSQL、SQLite、MySQL） |
| 文档解析 | 独立的 `docreader` 服务（Python + gRPC），支持 PDF、Word、图片、Excel、PPT 等 10+ 格式 |
| 任务队列 | asynq（基于 Redis）+ 定时任务 cron |
| 依赖注入 | dig（Uber 的依赖注入容器） |
| API 文档 | Swagger（`docs/swagger.json` 等） |
| 桌面端 | Wails v2（Go + Web 技术构建跨平台桌面应用） |

### 2.2 前端

| 技术 | 说明 |
|------|------|
| Vue 3 + TypeScript | 核心框架 |
| Vite | 构建工具 |
| TDesign Vue Next | UI 组件库 |
| Pinia | 状态管理 |
| Vue Router | 路由 |
| Vue I18n | 国际化（中/英/日/韩） |
| Marked + Katex + Mermaid | Markdown 渲染、LaTeX 公式、图表 |
| Pagefind | 站内搜索 |

### 2.3 向量数据库（多选）

- PostgreSQL + pgvector
- Elasticsearch
- Milvus
- Weaviate
- Qdrant

### 2.4 LLM / Embedding 支持（20+ 厂商）

OpenAI、Azure OpenAI、DeepSeek、通义千问、智谱、混元、豆包、Gemini、MiniMax、NVIDIA、Novita AI、SiliconFlow、OpenRouter、Ollama 等。

### 2.5 对象存储

本地、MinIO、AWS S3、火山引擎 TOS、阿里云 OSS

### 2.6 IM 集成

企业微信、飞书、Slack、Telegram、钉钉、Mattermost、微信

### 2.7 可观测性

- **Langfuse**：Agent ReAct 循环、Token 追踪、工具调用、流水线追踪
- **Jaeger / OpenTelemetry**：分布式链路追踪

## 三、系统架构特点

### 3.1 微服务化设计（Docker Compose / K8s）

系统由多个服务组成：

| 服务 | 职责 |
|------|------|
| `frontend` | Nginx 反向代理的 Web UI |
| `app` | 核心业务后端（Go） |
| `docreader` | 文档解析服务（Python gRPC） |
| `postgres` | 主数据库（ParadeDB v0.22.2，基于 PG17） |
| `redis` | 缓存 + 任务队列 + 限流 |
| `sandbox` | Agent Skills 沙箱执行环境（Docker 隔离） |
| `neo4j`（可选） | 知识图谱（GraphRAG） |
| `minio`（可选） | 对象存储 |
| `langfuse-*`（可选） | 自托管可观测性栈 |

### 3.2 模块化核心（`internal/` 目录）

```
internal/
├── agent/          # Agent 逻辑（ReAct 推理循环）
├── handler/        # HTTP API Handler
├── models/         # 数据模型
├── router/         # 路由注册
├── middleware/     # 中间件（认证、限流等）
├── datasource/     # 数据源连接器（飞书、Notion、语雀）
├── im/             # IM 渠道适配器
├── mcp/            # MCP 工具集成
├── sandbox/        # Skills 沙箱
├── searchutil/     # 检索工具（混合搜索、重排序）
├── stream/         # SSE 流式输出管理
├── tracing/        # 链路追踪
└── utils/          # 通用工具
```

## 四、核心功能模块

### 4.1 知识库管理

- **多类型知识库**：FAQ、文档型、Wiki 型
- **多源导入**：本地上传、文件夹导入、URL 导入、飞书/Notion/语雀自动同步
- **检索策略**：向量检索、BM25 关键词检索、混合检索、GraphRAG、父子分块

### 4.2 Agent 系统

- **ReAct 推理**：多步推理，自主决策调用工具
- **MCP 工具**：内置 MCP 服务 + 外部 MCP Server（支持 uvx/npx 启动）
- **Skills 系统**：预置技能（数据分析、文档协同等），沙箱隔离执行
- **自定义 Agent**：用户可配置知识库范围、模型、Prompt、工具集

### 4.3 Wiki Mode

- Agent 自动将原始文档转化为结构化 Markdown Wiki
- 页面间自动建立引用链接
- 配套 WikiBrowser 和交互式知识图谱可视化

### 4.4 多租户与共享空间

- 租户隔离的数据与权限体系
- 共享空间支持成员邀请、共享知识库和 Agent

## 五、部署方式

| 方式 | 说明 |
|------|------|
| **Docker Compose** | 一键启动，支持 Profile（`full`/`neo4j`/`minio`/`langfuse`）按需启用组件 |

| **桌面端** | Wails 构建的本地应用（`cmd/desktop/`） |
| **微信小程序** | 轻量移动端入口（`miniprogram/`） |

## 六、安全与运维

- **AES-256-GCM** 加密敏感字段（API Key、AppSecret）
- **SSRF 安全** HTTP 客户端，白名单机制
- **沙箱执行** Agent Skills（Docker 隔离）
- **自动数据库迁移**（`golang-migrate`），版本升级无感知
- **健康检查** 各服务均配置 Docker Healthcheck

---

## 七、总结

WeKnora 是一个**架构成熟、生态丰富、企业级就绪**的开源 RAG+Agent 知识框架：

- **模块化设计**：LLM、向量库、存储、数据源均可插拔替换
- **全链路覆盖**：从文档解析 → 向量化 → 检索 → LLM 推理 → Agent 工具调用 → 可观测性
- **多终端支持**：Web、桌面端、Chrome 插件、微信小程序、IM 机器人
- **企业级特性**：多租户、OIDC 认证、数据加密、沙箱隔离、权限控制
- **活跃迭代**：v0.5.1 版本已具备 Wiki Mode、Langfuse 可观测性、语雀连接器等功能
