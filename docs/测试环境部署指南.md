# WeKnora 测试环境部署指南（外部中间件版）

> 适用于：已有 PostgreSQL、Redis、阿里云 OSS，在新服务器上部署 WeKnora 测试环境。

---

## 一、前置准备

### 1.1 确认外部中间件信息

部署前，请确认以下信息已就绪：

```
┌─────────────────────────────────────────────────────────────┐
│  外部 PostgreSQL                                            │
│  - 地址: 192.168.1.100:5432  （示例，请替换为实际地址）       │
│  - 用户名: postgres                                         │
│  - 密码: your_password                                      │
│  - 数据库: WeKnora  （需提前创建，或让应用自动迁移）         │
│                                                             │
│  外部 Redis 6.0.6                                           │
│  - 地址: 192.168.1.101:6379  （示例）                       │
│  - 密码: your_redis_password                                │
│                                                             │
│  阿里云 OSS                                                 │
│  - AccessKey ID: your_access_key_id                         │
│  - AccessKey Secret: your_access_key_secret                 │
│  - Region: oss-cn-hangzhou                                  │
│  - Bucket: your-bucket-name                                 │
│                                                             │
│  LLM 服务（二选一）                                          │
│  - Ollama 本地服务: http://your_llm_host:11434              │
│  - 或云厂商 API Key（在 WeKnora UI 中配置）                  │
└─────────────────────────────────────────────────────────────┘
```

### 1.2 新服务器环境要求

| 项目 | 最低要求 | 推荐配置 |
|------|---------|---------|
| CPU | 2 核 | 4 核 |
| 内存 | 4 GB | 8 GB |
| 磁盘 | 50 GB SSD | 100 GB SSD |
| 网络 | 可访问外部 PG/Redis/OSS/LLM | 内网互通更佳 |
| 操作系统 | Ubuntu 20.04+ / CentOS 7+ | Ubuntu 22.04 LTS |

### 1.3 安装 Docker 和 Docker Compose

```bash
# Ubuntu 22.04 示例
sudo apt-get update
sudo apt-get install -y ca-certificates curl gnupg

# 添加 Docker 官方 GPG 密钥
sudo install -m 0755 -d /etc/apt/keyrings
curl -fsSL https://download.docker.com/linux/ubuntu/gpg | sudo gpg --dearmor -o /etc/apt/keyrings/docker.gpg
sudo chmod a+r /etc/apt/keyrings/docker.gpg

# 添加仓库
echo \
  "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.gpg] https://download.docker.com/linux/ubuntu \
  $(. /etc/os-release && echo "$VERSION_CODENAME") stable" | \
  sudo tee /etc/apt/sources.list.d/docker.list > /dev/null

# 安装 Docker
sudo apt-get update
sudo apt-get install -y docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin

# 验证
sudo docker --version
sudo docker compose version

# 将当前用户加入 docker 组（免 sudo）
sudo usermod -aG docker $USER
# 退出并重新登录后生效
```

## 三、配置环境变量

### 3.1 创建 .env 文件

```bash
cp .env.example .env
```

### 3.2 编辑 .env（关键配置）

以下是针对外部中间件的**最小化配置**，复制粘贴后替换为你的实际值：

```bash
# ==========================================
# 基础配置
# ==========================================
WEKNORA_VERSION=latest
GIN_MODE=release
LOG_LEVEL=info
TZ=Asia/Shanghai
WEKNORA_LANGUAGE=zh-CN
DISABLE_REGISTRATION=false

# ==========================================
# 数据库（外部 PostgreSQL）
# ==========================================
DB_DRIVER=postgres
DB_HOST=192.168.1.100          # <-- 替换为你的 PostgreSQL 地址
DB_PORT=5432
DB_USER=postgres
DB_PASSWORD=your_pg_password   # <-- 替换
DB_NAME=WeKnora

# ==========================================
# Redis（外部 Redis 6.0.6）
# ==========================================
STREAM_MANAGER_TYPE=redis
REDIS_ADDR=192.168.1.101:6379  # <-- 替换为你的 Redis 地址
REDIS_PASSWORD=your_redis_pass # <-- 替换
REDIS_DB=0
REDIS_PREFIX=stream:

# ==========================================
# 向量存储（使用 PostgreSQL + pgvector）
# ==========================================
RETRIEVE_DRIVER=postgres

# 如果有独立向量库（ES/Milvus/Qdrant），可切换：
# RETRIEVE_DRIVER=elasticsearch_v8
# RETRIEVE_DRIVER=qdrant
# RETRIEVE_DRIVER=milvus

# ==========================================
# 对象存储（阿里云 OSS）
# ==========================================
STORAGE_TYPE=cos
COS_SECRET_ID=your_access_key_id      # <-- 替换
COS_SECRET_KEY=your_access_key_secret # <-- 替换
COS_REGION=oss-cn-hangzhou            # <-- 替换为你的区域
COS_BUCKET_NAME=your-bucket-name      # <-- 替换
COS_PATH_PREFIX=weknora/
COS_ENABLE_OLD_DOMAIN=true

# 可选：限制用户只能使用 OSS
# STORAGE_ALLOW_LIST=cos

# ==========================================
# LLM 服务
# ==========================================
# 如果使用本地/局域网 Ollama：
OLLAMA_BASE_URL=http://192.168.1.102:11434   # <-- 替换为实际地址

# 如果使用云厂商 LLM（OpenAI/DeepSeek/通义千问等），
# 部署后在 WeKnora UI → 模型管理 中配置 API Key

# ==========================================
# 文档解析
# ==========================================
DOCREADER_ADDR=docreader:50051
DOCREADER_TRANSPORT=grpc

# ==========================================
# 安全配置（生产务必修改！）
# ==========================================
JWT_SECRET=$(openssl rand -base64 32)              # 随机生成
TENANT_AES_KEY=$(openssl rand -base64 24)"!!"      # 32字节
SYSTEM_AES_KEY=$(openssl rand -base64 24)"!!"      # 32字节

# ==========================================
# 网络与端口
# ==========================================
APP_HOST=app
APP_PORT=8080
APP_BACKEND_PORT=8080
APP_SCHEME=http
FRONTEND_PORT=80
DOCREADER_PORT=50051

# ==========================================
# 性能与功能开关
# ==========================================
CONCURRENCY_POOL_SIZE=3
MAX_FILE_SIZE_MB=50
ENABLE_GRAPH_RAG=false
NEO4J_ENABLE=false

# Agent 沙箱（测试环境可关闭）
WEKNORA_SANDBOX_MODE=disabled

# ==========================================
# 可选：Langfuse 可观测性
# ==========================================
# 接入 Langfuse Cloud（最简单）：
# LANGFUSE_PUBLIC_KEY=pk-lf-xxxxxxxx
# LANGFUSE_SECRET_KEY=sk-lf-xxxxxxxx
# LANGFUSE_HOST=https://cloud.langfuse.com

# ==========================================
# 其他（保持默认即可）
# ==========================================
AUTO_RECOVER_DIRTY=true
WEB_PROXY=
APK_MIRROR_ARG=
```

### 3.3 生成强密码（可选但推荐）

```bash
# 生成 JWT_SECRET
openssl rand -base64 32

# 生成 32 字节 AES 密钥
openssl rand -base64 24
# 输出后手动补 "!!" 到末尾，确保正好 32 字节
```

## 四、配置精简版 Docker Compose

由于 PostgreSQL、Redis、MinIO 均为外部服务，需要创建精简版 `docker-compose.yml`。

### 4.1 备份原文件

```bash
cp docker-compose.yml docker-compose.yml.full
```

### 4.2 创建精简版 docker-compose.yml

```bash
cat > docker-compose.yml << 'EOF'
services:
  frontend:
    image: wechatopenai/weknora-ui:${WEKNORA_VERSION:-latest}
    build:
      context: ./frontend
      args:
        - MAX_FILE_SIZE_MB=${MAX_FILE_SIZE_MB:-50}
    container_name: WeKnora-frontend
    ports:
      - "${FRONTEND_PORT:-80}:80"
    environment:
      - MAX_FILE_SIZE_MB=${MAX_FILE_SIZE_MB:-50}
      - APP_HOST=${APP_HOST:-app}
      - APP_PORT=${APP_BACKEND_PORT:-8080}
      - APP_SCHEME=${APP_SCHEME:-http}
    depends_on:
      app:
        condition: service_healthy
    networks:
      - WeKnora-network
    restart: unless-stopped

  app:
    image: wechatopenai/weknora-app:${WEKNORA_VERSION:-latest}
    build:
      context: .
      dockerfile: docker/Dockerfile.app
      args:
        - APK_MIRROR_ARG=${APK_MIRROR_ARG:-}
    container_name: WeKnora-app
    ports:
      - "${APP_PORT:-8080}:8080"
    volumes:
      - data-files:/data/files
      - docreader-tmp:/tmp/docreader:ro
      - ./config/config.yaml:/app/config/config.yaml
      - ./skills/preloaded:/app/skills/preloaded
    healthcheck:
      test: ["CMD", "curl", "-f", "http://localhost:8080/health"]
      interval: 30s
      timeout: 10s
      retries: 3
      start_period: 60s
    environment:
      - LOG_LEVEL=${LOG_LEVEL:-}
      - COS_SECRET_ID=${COS_SECRET_ID:-}
      - COS_SECRET_KEY=${COS_SECRET_KEY:-}
      - COS_REGION=${COS_REGION:-}
      - COS_BUCKET_NAME=${COS_BUCKET_NAME:-}
      - COS_APP_ID=${COS_APP_ID:-}
      - COS_PATH_PREFIX=${COS_PATH_PREFIX:-}
      - COS_ENABLE_OLD_DOMAIN=${COS_ENABLE_OLD_DOMAIN:-}
      - GIN_MODE=${GIN_MODE:-release}
      - DISABLE_REGISTRATION=${DISABLE_REGISTRATION:-false}
      - DB_DRIVER=postgres
      - DB_HOST=${DB_HOST}
      - DB_PORT=${DB_PORT}
      - DB_USER=${DB_USER}
      - DB_PASSWORD=${DB_PASSWORD}
      - DB_NAME=${DB_NAME}
      - TZ=${TZ:-Asia/Shanghai}
      - WEKNORA_LANGUAGE=${WEKNORA_LANGUAGE:-zh-CN}
      - OTEL_EXPORTER_OTLP_ENDPOINT=${OTEL_EXPORTER_OTLP_ENDPOINT:-}
      - OTEL_SERVICE_NAME=${OTEL_SERVICE_NAME:-WeKnora}
      - OTEL_TRACES_EXPORTER=${OTEL_TRACES_EXPORTER:-}
      - OTEL_METRICS_EXPORTER=${OTEL_METRICS_EXPORTER:-}
      - OTEL_LOGS_EXPORTER=${OTEL_LOGS_EXPORTER:-}
      - OTEL_PROPAGATORS=${OTEL_PROPAGATORS:-}
      - LANGFUSE_ENABLED=${LANGFUSE_ENABLED:-}
      - LANGFUSE_HOST=${LANGFUSE_HOST:-}
      - LANGFUSE_PUBLIC_KEY=${LANGFUSE_PUBLIC_KEY:-}
      - LANGFUSE_SECRET_KEY=${LANGFUSE_SECRET_KEY:-}
      - RETRIEVE_DRIVER=${RETRIEVE_DRIVER:-}
      - DOCREADER_ADDR=${DOCREADER_ADDR:-docreader:50051}
      - DOCREADER_TRANSPORT=${DOCREADER_TRANSPORT:-grpc}
      - STORAGE_TYPE=${STORAGE_TYPE:-}
      - LOCAL_STORAGE_BASE_DIR=${LOCAL_STORAGE_BASE_DIR:-}
      - AUTO_RECOVER_DIRTY=${AUTO_RECOVER_DIRTY:-true}
      - OLLAMA_BASE_URL=${OLLAMA_BASE_URL:-}
      - STREAM_MANAGER_TYPE=${STREAM_MANAGER_TYPE:-}
      - REDIS_ADDR=${REDIS_ADDR}
      - REDIS_USERNAME=${REDIS_USERNAME:-}
      - REDIS_PASSWORD=${REDIS_PASSWORD:-}
      - REDIS_DB=${REDIS_DB:-}
      - REDIS_PREFIX=${REDIS_PREFIX:-}
      - ENABLE_GRAPH_RAG=${ENABLE_GRAPH_RAG:-}
      - NEO4J_ENABLE=${NEO4J_ENABLE:-}
      - TENANT_AES_KEY=${TENANT_AES_KEY}
      - SYSTEM_AES_KEY=${SYSTEM_AES_KEY}
      - SSRF_WHITELIST=${SSRF_WHITELIST:-}
      - CONCURRENCY_POOL_SIZE=${CONCURRENCY_POOL_SIZE:-5}
      - JWT_SECRET=${JWT_SECRET}
      - CRYPTO_MASTER_KEY=${CRYPTO_MASTER_KEY:-}
      - CRYPTO_SALT=${CRYPTO_SALT:-}
      - MAX_FILE_SIZE_MB=${MAX_FILE_SIZE_MB:-50}
      - WEKNORA_SANDBOX_MODE=${WEKNORA_SANDBOX_MODE:-docker}
      - WEKNORA_SANDBOX_TIMEOUT=${WEKNORA_SANDBOX_TIMEOUT:-60}
      - WEKNORA_SANDBOX_DOCKER_IMAGE=${WEKNORA_SANDBOX_DOCKER_IMAGE:-}
      - WEKNORA_AGENT_LLM_TIMEOUT=${WEKNORA_AGENT_LLM_TIMEOUT:-}
      - APK_MIRROR_ARG=${APK_MIRROR_ARG:-}
    depends_on:
      docreader:
        condition: service_healthy
    networks:
      - WeKnora-network
    restart: unless-stopped

  docreader:
    image: wechatopenai/weknora-docreader:${WEKNORA_VERSION:-latest}
    build:
      context: .
      dockerfile: docker/Dockerfile.docreader
      args:
        - APT_MIRROR=${APT_MIRROR:-}
    container_name: WeKnora-docreader
    ports:
      - "${DOCREADER_PORT:-50051}:50051"
    volumes:
      - docreader-tmp:/tmp/docreader
    environment:
      - DOCREADER_IMAGE_OUTPUT_DIR=/tmp/docreader
      - MAX_FILE_SIZE_MB=${MAX_FILE_SIZE_MB:-}
    healthcheck:
      test: ["CMD", "grpc_health_probe", "-addr=localhost:50051"]
      interval: 30s
      timeout: 10s
      retries: 3
      start_period: 60s
    networks:
      - WeKnora-network
    restart: unless-stopped

networks:
  WeKnora-network:
    driver: bridge

volumes:
  data-files:
  docreader-tmp:
EOF
```

> **关键变化**：
> - 移除了 `postgres`、`redis`、`minio` 服务
> - `app` 的 `depends_on` 中移除了 `postgres` 和 `redis`
> - 所有环境变量改为从 `.env` 读取，便于统一管理

## 五、启动服务

### 5.1 拉取镜像（国内服务器建议配置镜像加速）

```bash
# 如访问 Docker Hub 慢，可配置阿里云/腾讯云镜像加速
sudo mkdir -p /etc/docker
sudo tee /etc/docker/daemon.json << 'EOF'
{
  "registry-mirrors": [
    "https://mirror.ccs.tencentyun.com",
    "https://hub-mirror.c.163.com"
  ]
}
EOF
sudo systemctl restart docker

# 拉取镜像
docker compose pull
```

### 5.2 启动核心服务

```bash
cd /opt/WeKnora

# 前台启动（观察日志，首次启动推荐）
docker compose up

# 或后台启动
docker compose up -d
```

### 5.3 查看启动状态

```bash
# 查看容器状态
docker compose ps

# 查看实时日志
docker compose logs -f app

# 查看所有服务日志
docker compose logs -f
```

**预期输出**：
```
NAME                IMAGE                              STATUS
WeKnora-app         wechatopenai/weknora-app:latest    Up 2 minutes (healthy)
WeKnora-docreader   wechatopenai/weknora-docreader:latest  Up 2 minutes (healthy)
WeKnora-frontend    wechatopenai/weknora-ui:latest     Up 1 minute
```

```bash
# 1. 检查 App 健康接口

# 预期: {"status":"ok"}

# 2. 检查前端可访问
curl -I http://localhost
# 预期: HTTP/1.1 200 OK

# 3. 检查 Docreader gRPC（从容器内）

```

### 6.2 浏览器访问

```
Web UI:    http://服务器IP/
API 文档:  http://服务器IP:8080/swagger/index.html
```

首次访问：
1. 点击右上角 **注册**，创建管理员账号
2. 登录后进入 **模型管理**，配置 LLM（Ollama 或云厂商 API）
3. 创建知识库，上传文档测试

```bash

apk add redis
redis-cli -h REDIS_ADDR -a REDIS_PASSWORD ping

# 退出容器
```

## 七、常见问题

### Q1: App 启动失败，日志显示数据库连接错误

```
failed to initialize database, got error ... connection refused
```

**排查**：
```bash
# 1. 确认 .env 中 DB_HOST 是外部可达的 IP/域名（不能是 localhost 或 postgres）
# 2. 确认 PostgreSQL 允许该 IP 连接（pg_hba.conf）
# 3. 确认防火墙/安全组放行 5432 端口
# 4. 从容器内测试连通性：
docker exec -it WeKnora-app sh
wget -O- -q http://DB_HOST:5432  # 虽然不返回 HTTP，但能验证网络连通
```

### Q2: Redis 连接失败

```
ERR Client sent AUTH, but no password is set
```

**解决**：如果 Redis 没有设置密码，将 `.env` 中的 `REDIS_PASSWORD` 留空（不要写任何值）。

### Q3: 上传文件失败或图片不显示

**排查**：
1. 确认 OSS 的 Bucket 存在且 AccessKey 有读写权限
2. 确认 `COS_REGION` 与 Bucket 实际区域一致
3. 确认 Bucket CORS 规则允许 WeKnora 域名访问

### Q4: LLM 调用超时或无响应

**排查**：
```bash
# 1. 确认 Ollama 服务可访问（如果使用 Ollama）
docker exec -it WeKnora-app sh
wget -O- -q http://OLLAMA_HOST:11434/api/tags

# 2. 确认模型已下载
ollama list

# 3. 如果是云厂商 API，在 UI 中检查 API Key 是否正确
```

### Q5: 内存不足导致服务卡顿

**症状**：容器频繁重启、响应慢、OOMKilled

**解决**：
```bash
# 查看内存使用
docker stats

# 如果 2核4G 不够，可添加 Swap（临时缓解）
sudo fallocate -l 4G /swapfile
sudo chmod 600 /swapfile
sudo mkswap /swapfile
sudo swapon /swapfile

# 长期方案：升级服务器配置至 4核8G
```

## 八、后续操作

### 8.1 配置 LLM

1. 访问 Web UI → **模型管理**
2. 添加模型：
   - **Ollama**：选择 "Ollama" 类型，填写 Base URL（如 `http://192.168.1.102:11434`）
   - **云厂商**：选择对应厂商，填写 API Key
3. 设置默认模型：至少配置一个 Chat 模型和一个 Embedding 模型

### 8.2 创建知识库测试

1. Web UI → **知识库** → 创建知识库
2. 选择 Embedding 模型
3. 上传 PDF/Word 文档
4. 等待解析完成（状态变为 "已完成"）
5. 进入会话，选择知识库进行问答测试

### 8.3 停止/重启服务

```bash
# 停止
docker compose down

# 重启
docker compose restart

# 查看日志
docker compose logs -f --tail=100 app
```

### 8.4 升级版本

```bash
cd /opt/WeKnora
git fetch --tags
git checkout v0.6.0   # 替换为最新版本

docker compose pull
docker compose up -d
```
